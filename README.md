# agenda_flutter_chareun
## Programación de Aplicaciones Móviles III - Actividad Integradora 2

Proyecto de Agenda de Contactos en Flutter.

## Features
*  Login
    *  Mensaje de error si son incorrectas
    *  Se almacena sesión con SharedPreferences
    *  Si el usuario está logueado, se muestra directamente la agenda

*  Registrar usuario
      
*  Pantalla de agenda con lista de contactos
    * Permite buscar un contacto por nombre/apellido
    * Permite agregar un contacto
      *  Datos: Nombre, apellido, teléfono, email
      *  La lista se actualiza automáticamente
   *  Permite editar un contacto
   *  Permite eliminar un contacto
